## Sobre o projeto

Este repositório contém o desenvolvimento do meu portfólio pessoal, criado para reunir minha trajetória acadêmica, meus conhecimentos técnicos e os projetos que venho desenvolvendo na área de tecnologia.

A aplicação foi construída com foco em uma experiência de navegação intuitiva, identidade visual consistente e organização do conteúdo.

Mais do que apresentar projetos, este portfólio representa parte da minha evolução como desenvolvedor e a aplicação prática dos conhecimentos adquiridos durante minha formação em Análise e Desenvolvimento de Sistemas.

## Executar localmente

Para visualizar o projeto em ambiente local, siga os passos abaixo.

**Pré-requisitos:** Node.js e npm instalados.

```bash
# Clonar o repositório
git clone https://github.com/Carvalho-Eduardo/portfolio-pessoal.git

# Acessar a pasta
cd portfolio-pessoal

# Instalar as dependências
npm install

# Iniciar o ambiente de desenvolvimento
npm run dev
```

Após iniciar o servidor, acesse o endereço local apresentado no terminal.
